## 1. Agent Graphs 是什么

Langfuse 中的 Agent Graphs（智能体图谱）功能，为复杂的 AI 智能体工作流提供可视化呈现，帮助你理解和调试多步推理过程以及智能体之间的交互。

## 2. 快速上手

图谱视图目前处于 Beta 阶段，欢迎反馈意见。

一条 Trace 会以两种方式呈现出图谱：

1. **从 Observation 中推断**。只要 Trace 中包含任何非 span、event 或 generation 类型的 Observation，Langfuse 就会把这条 Trace 解读为智能体式（agentic）的，并根据 Observation 的时序和嵌套关系自动推断出对应的图谱。
2. **来自 LangGraph 集成**。使用 LangGraph 集成时，图谱会自动展示。

> Observation 类型：查看所有可用的 Observation 类型以及设置方法。
> LangGraph：查看 LangGraph 集成指南，了解如何将 LangGraph 与 Langfuse 原生集成，实现端到端的 LLM Agent 追踪示例。

## 3. 视图模式：聚合视图与展开视图

同一条 Trace 可以用两种方式绘制。可以通过图谱左上角的 Aggregated / Expanded 切换按钮来回切换，你选择的模式会在不同 Trace 之间被记住。

二者的区别在于如何处理重复出现的步骤——是"一个步骤名对应一个节点"，还是"一次调用对应一个节点"：

| | 聚合视图（默认） | 展开视图（"按实际运行"） |
|---|---|---|
| 一个节点代表… | 一个唯一的步骤名 | 一次独立调用 |
| 重复调用 | 合并为带计数器的单个节点 | 各自显示为独立节点 |
| 循环 | 绘制为环（边会回绕） | 展开为无环图（DAG） |
| 阅读体验 | 像是在看智能体的整体结构 | 像是在逐步跟踪具体的执行过程 |
| 最适合 | 一眼看懂整体结构和复杂度 | 跟踪或调试某一次具体执行 |

### 3.1 聚合视图（Aggregated）

聚合视图是一种精简的总览。名称相同的步骤会被合并成一个带计数器的节点——比如 `retrieve_docs (3/3)` 表示这个步骤运行了三次——反复调用同一个工具形成的循环，也会被画成一个环，而不是一长串链条。这样即使是一个很"忙"的智能体，图谱依然保持可读：你能看到有多少个不同的步骤、以及它们之间如何连接，而不必把每一次调用都摆到屏幕上。这是回答"这个智能体到底在做什么、有多复杂"这个问题最快的方式。

### 3.2 展开视图（Expanded）

展开视图展示的是实际运行的完整过程。每一次调用都是独立的一个节点，所以三次 `litellm_request` 调用就是三个不同的节点，循环也会按执行顺序展开成一张有向无环图。这种视图更贴近字面意义上的执行过程，也更接近 Trace 树本身——当你想完整跟踪某一次具体运行、或者精确定位问题发生的位置时，这才是应该用的视图。规模更大的 Trace，在这个视图里自然会产生更多节点。

没有哪种视图是"更正确"的——它们回答的是不同的问题。想理解智能体的结构，用聚合视图；想走一遍某次具体的运行，用展开视图。

---

## 4. 📝 小结

- Langfuse 的 Agent Graphs 功能，把复杂的多步智能体工作流可视化，方便理解和调试
- 图谱有两种生成方式：从 Observation 类型和时序自动推断，或通过 LangGraph 集成自动展示
- 聚合视图按步骤名合并节点，适合快速把握整体结构和复杂度
- 展开视图按实际调用逐一展示节点，适合跟踪和调试某次具体执行
- 该功能目前处于 Beta 阶段
