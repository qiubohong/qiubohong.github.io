## 1. 项目简介

Agent-Graph 是一个基于上下文工程（Context Engineering）理念构建的多智能体系统（Multi-Agent System）。它集成了子智能体（Sub-agent）、长期记忆（Long-term Memory）、MCP、基于智能体的工作流（Agent-based Workflow）等能力。通过将上下文工程的最佳实践融入可视化开发体验，Agent-Graph 让开发者可以快速构建、测试和部署复杂的多智能体应用。

> 文档地址：https://keta1930.github.io/agent-graph/

## 3. 部署指南

> 📖 详细安装文档：`docs/first-steps/install.md`

### 3.1 系统要求

| 组件 | 要求 |
|---|---|
| 操作系统 | Linux、macOS 或 Windows（需要 WSL2） |
| Docker | 20.10+ 版本，并附带 Docker Compose |
| Python | 3.11+ 版本 |
| 内存 | 最低 4GB（推荐 8GB） |
| 存储 | 至少 10GB 可用空间 |

### 3.2 快速开始

**3.2.1 克隆项目**

```bash
git clone https://github.com/keta1930/agent-graph.git
cd agent-graph
```

**3.2.2 配置并启动 Docker 服务**

```bash
cp .env.example .env
# 启动前请填写所有空白的凭证和密钥
python agent_graph/scripts/generate_jwt_secret.py
docker compose --env-file .env -f docker/docker-compose.yml up -d
```

默认服务地址：

- MongoDB Express（数据库管理）：http://localhost:20041
- MinIO Console（文件存储）：http://localhost:20043

**3.2.3 部署后端**

使用 uv（推荐）：

```bash
uv sync
uv run --env-file .env fastapi run
```

使用 pip：

```bash
pip install -r requirements.txt
dotenv -f .env run -- fastapi run
```

后台运行：

```bash
nohup uv run --env-file .env fastapi run > app.log 2>&1 &
```

**3.2.4 访问应用**

打开 `PUBLIC_API_BASE_URL` 配置的地址（默认：http://localhost:20050）。

- 登录页面：使用 `.env` 中配置的用户名和密码进行管理员登录
- 注册页面：新用户可通过邀请码注册

其他访问入口：

- API 文档：http://localhost:20050/docs
- 健康检查：http://localhost:20050/health

**前端开发（可选）**

如果需要修改前端代码：

```bash
cd frontend
npm install
npm run dev  # 使用根目录 .env 中的 FRONTEND_PORT
npm run build  # 构建生产版本
```

> 说明：仓库中已包含预构建好的前端文件，只有在开发或定制前端时才需要执行这一步。

## 4. 核心功能

### 4.1 核心组件

| 功能 | 描述 | 文档 |
|---|---|---|
| Agent | 具备理解目标、使用工具、迭代优化、维护上下文和长期记忆能力的 AI 实体，能通过自主执行行动来解决开放式任务 | Agent 文档 |
| Graph（工作流） | 将多个智能体编排成结构化工作流，通过节点和边定义执行流程，适合可预测的多阶段任务 | Graph 文档 |
| Model | 支持 LLM 和 VLM 模型（兼容 OpenAI），API Key 配置灵活 | Model 文档 |
| Memory | 短期记忆维持对话上下文，长期记忆跨会话存储用户偏好和 Agent 知识库 | Memory 文档 |
| Prompt Center | 集中管理可复用的 Prompt 模板，支持分类、导入/导出，以及跨项目引用 | Prompt 文档 |
| Projects | 将对话组织成带共享文件的集合 | Projects 文档 |

### 4.2 工作流能力

| 功能 | 描述 | 文档 |
|---|---|---|
| 可视化图谱编辑器 | 前端拖拽式工作流设计，支持线性、并行、条件和嵌套图谱类型，所见即所得 | Graph 文档 |
| 子图嵌套 | 将整个 Graph 作为单个节点使用以实现嵌套，支持模块化、可复用、分层的工作流构建 | Subgraph 文档 |
| Handoffs（智能路由） | 节点动态选择下一个执行节点，支持智能决策、条件分支和迭代优化循环 | Handoffs 文档 |
| Task（任务调度） | 定时或周期性自动执行 Graph，支持 cron 表达式、并发实例和执行历史追踪 | Task 文档 |

### 4.3 扩展能力

| 功能 | 描述 | 文档 |
|---|---|---|
| MCP 协议集成 | 通过标准化协议连接外部工具和数据源（数据库、API、文件系统、云服务等），一次接入、随处使用 | MCP 文档 |
| 内置工具集 | 提供资源创建（Agent Creator、Graph Designer、MCP Builder、Prompt Generator、Task Manager）、协作（Sub-agent、File Tool）和查询（Memory Tool、System Operations）等系统工具 | Tools 文档 |

### 4.4 协作与管理

| 功能 | 描述 | 文档 |
|---|---|---|
| 团队协作 | 管理员创建邀请码、管理团队成员、分配角色权限（超级管理员、管理员、普通用户） | Team Management |
| 对话管理 | 支持查看对话历史、管理文件附件、维护会话上下文 | Quick Start |

## 6. 前端功能展示

- **对话欢迎页**：用于开始与 Agent 对话的入口界面，支持快速选择预设 Agent 或新建对话
- **工作台 — Agent 管理**：创建、配置和管理 Agent，设置系统 Prompt、工具和模型参数
- **工作台 — 工作流管理**：可视化拖拽式工作流设计器，支持多种节点类型和复杂流程编排
- **工作台 — 模型管理**：配置和管理多个 LLM 模型，设置 API Key 和模型参数
- **工作台 — 系统工具箱**：查看和配置内置系统工具，包括资源创建和协作工具
- **工作台 — MCP 管理**：管理 MCP 服务器连接，配置外部工具和数据源集成
- **工作台 — Prompt 管理**：集中管理可复用的 Prompt 模板，支持分类和版本控制
- **工作台 — 文件管理**：管理上传的文件和附件，支持文件预览和整理
- **工作台 — 记忆管理**：查看和管理 Agent 的长期记忆和知识库

## 8. 📝 小结

- Agent-Graph 是一个基于上下文工程理念的开源多智能体系统，集成子智能体、长期记忆、MCP、工作流编排等能力
- 核心组件包括Agent、Graph（工作流）、Model、Memory、Prompt Center、Projects 六大模块
