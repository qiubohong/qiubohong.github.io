> **支持版本**：Python v0.1.0 / TypeScript v0.2.0 / Go v0.1.0 / Java v0.2.0

***LoopAgent*** 类是一种[模板工作流](https://adk.dev/agents/workflow-agents/) Agent，它会在循环中执行子 Agent，直到达到指定的迭代次数或满足终止条件为止。当你的工作流涉及重复操作或迭代精化时（比如反复修改代码或文档），就可以使用 ***LoopAgent***。

与其他模板工作流一样，***LoopAgent*** 对象的执行不受 AI 模型控制，其子 Agent 的执行顺序是确定性的。循环内的子 Agent 可以使用也可以不使用 AI 模型，但这些子 Agent 的整体执行最终由你定义的 ***LoopAgent*** 对象来管理。

## 示例场景

假设你想构建一个能生成食物图片的 Agent，但有时当你想生成特定数量的物品（比如香蕉）时，Agent 生成的图片中物品数量会不对（比如生成了 7 根香蕉）。你有两个工具：`Generate Image`（生成图片）和 `Count Food Items`（计数食物）。如果你的目标是持续生成图片，直到正确生成指定数量的物品，或者达到一定迭代次数后停止，就可以用 ***LoopAgent*** 工作流来构建这个 Agent。

## 工作原理

当 `LoopAgent` 的 `Run Async` 方法被调用时，它会执行以下操作：

**1. 子 Agent 执行**

它会*按顺序*遍历子 Agent 列表，对*每个*子 Agent 调用其 `Run Async` 方法。

**2. 终止检查**

这里有个关键点：`LoopAgent` 本身**不会**自行决定何时停止循环。你**必须**实现一个终止机制来防止无限循环。常见的策略有两种：

- **最大迭代次数**：在 `LoopAgent` 中设置最大迭代次数，**达到该次数后循环将自动终止**。
- **子 Agent 发出终止信号**：设计一个或多个子 Agent 来评估某个条件（比如"文档质量是否足够好？"、"是否已达成共识？"）。如果条件满足，子 Agent 可以发出终止信号（比如触发自定义事件、在共享上下文中设置标志，或返回特定值）。

## 完整示例：迭代式文档改进

设想这样一个场景：你想对一篇文档进行迭代改进：

- **Writer Agent（写作 Agent）**：一个 `LlmAgent`，负责生成或精化某个主题的草稿。
- **Critic Agent（评审 Agent）**：一个 `LlmAgent`，负责评审草稿，找出需要改进的地方。

```python
LoopAgent(sub_agents=[WriterAgent, CriticAgent], max_iterations=5)
```

在这个设置中，`LoopAgent` 负责管理整个迭代过程。`CriticAgent` 可以被**设计为在文档达到满意质量时返回"STOP"信号**，从而阻止进一步迭代。或者，也可以用 `max iterations` 参数将流程限制在固定的循环次数内，或者通过外部逻辑来决定何时停止。**循环最多运行五次**，确保迭代精化不会无限持续下去。

```python
from google.adk.agents import LoopAgent, LlmAgent, SequentialAgent
from google.adk.tools.tool_context import ToolContext
from google.adk.agents.callback_context import CallbackContext

# --- 常量 ---
GEMINI_MODEL = "gemini-2.5-flash"

# --- 状态键 ---
STATE_CURRENT_DOC = "current_document"
STATE_CRITICISM = "criticism"
# 定义评审 Agent 用于表示完成的精确短语
COMPLETION_PHRASE = "No major issues found."

# --- 工具定义 ---
def exit_loop(tool_context: ToolContext):
    """仅当评审意见表明无需进一步修改时调用此函数，表示迭代过程应当结束。"""
    print(f"  [工具调用] exit_loop 由 {tool_context.agent_name} 触发")
    tool_context.actions.escalate = True
    tool_context.actions.skip_summarization = True
    # 工具通常应返回 JSON 可序列化的输出，这里返回空字典
    return {}

# --- Agent 前置回调 ---
def update_initial_topic_state(callback_context: CallbackContext):
    """确保在流水线启动前，状态中已设置 'initial_topic'。"""
    callback_context.state['initial_topic'] = callback_context.state.get(
        'initial_topic', 'a robot developing unexpected emotions'
    )

# --- Agent 定义 ---

# 步骤 1：初始写作 Agent（仅在开始时运行一次）
initial_writer_agent = LlmAgent(
    name="InitialWriterAgent",
    model=GEMINI_MODEL,
    include_contents='none',
    instruction=f"""
    你是一个创意写作助手，负责开始一个故事。

    写一个*非常基础*的短故事初稿（仅 1-2 句简单的句子）。
    保持简洁朴素——暂时不要添加描述性语言。
    主题：{{initial_topic}}

    *只*输出故事/文档文本，不要添加介绍或解释。
    """,
    description="根据主题写出初始文档草稿，力求有一定的初始内容。",
    output_key=STATE_CURRENT_DOC
)

# 步骤 2a：评审 Agent（在精化循环内部）
critic_agent_in_loop = LlmAgent(
    name="CriticAgent",
    model=GEMINI_MODEL,
    include_contents='none',
    instruction=f"""
    你是一个建设性评审 AI，负责审阅短故事草稿。

    **待审阅文档：**
    ```
    {{current_document}}
    ```

    **完成标准（所有条件均须满足）：**
    1. 至少 4 句话
    2. 有清晰的开头、中间和结尾
    3. 包含至少一个描述性细节（感官或情感）

    **任务：**
    对照上述标准检查文档。

    如果有任何标准**未**满足，请提供具体的改进反馈。
    *只*输出评审文本。

    如果**所有**标准均已满足，请*精确*回复："{COMPLETION_PHRASE}"
    """,
    description="审阅当前草稿，如需明显改进则提供评审意见，否则发出完成信号。",
    output_key=STATE_CRITICISM
)

# 步骤 2b：精化/退出 Agent（在精化循环内部）
refiner_agent_in_loop = LlmAgent(
    name="RefinerAgent",
    model=GEMINI_MODEL,
    include_contents='none',  # 仅通过占位符依赖状态
    instruction=f"""
    你是一个创意写作助手，负责根据反馈精化文档，或退出流程。

    **当前文档：**
    ```
    {{current_document}}
    ```

    **评审/建议：**
    {{criticism}}

    **任务：**
    分析"评审/建议"。

    如果评审*精确*为 "{COMPLETION_PHRASE}"：
    你**必须**调用 'exit_loop' 函数，不要输出任何文本。

    否则（评审包含可操作的反馈）：
    仔细应用建议来改进"当前文档"，*只*输出精化后的文档文本。

    不要添加解释。要么输出精化后的文档，要么调用 exit_loop 函数。
    """,
    description="根据评审精化文档，或在评审表明完成时调用 exit_loop。",
    tools=[exit_loop],  # 提供 exit_loop 工具
    output_key=STATE_CURRENT_DOC  # 用精化后的版本覆盖 state['current_document']
)

# 步骤 2：精化循环 Agent
refinement_loop = LoopAgent(
    name="RefinementLoop",
    # Agent 顺序至关重要：先评审，再精化/退出
    sub_agents=[
        critic_agent_in_loop,
        refiner_agent_in_loop,
    ],
    max_iterations=5  # 限制循环次数
)

# 步骤 3：整体顺序流水线
# 为兼容 ADK 工具，根 Agent 必须命名为 `root_agent`
root_agent = SequentialAgent(
    name="IterativeWritingPipeline",
    sub_agents=[
        initial_writer_agent,  # 首先运行，创建初始文档
        refinement_loop        # 然后运行评审/精化循环
    ],
    before_agent_callback=update_initial_topic_state,  # 在状态中设置初始主题
    description="先写出初始文档，然后使用退出工具通过评审迭代精化。"
)
```
