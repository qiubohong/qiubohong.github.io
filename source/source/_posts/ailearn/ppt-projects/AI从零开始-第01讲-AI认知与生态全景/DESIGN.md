# DESIGN.md — 第 01 讲：AI 认知与生态全景（优化版）

## 1. 画布与全局母版

- 画布：1280 × 720（16:9），padding 上下 20px、左右 60px。
- 三区母版（内容页固定）：
  - A · 标题块：0–120px，页面主标题 34px bold，左上 kicker 标签 14px 琥珀橙
  - B · 内容区：120–660px（可用 540px）
  - C · 页脚条：660–720px，左侧「AI 从零开始 · 第 1 讲」+ 右侧页码 `NN / 11`，14px 灰 #5B6B7A
- 封面 / 深色页用渐变 `linear-gradient(135deg, #16263F 0%, #1E3A5F 100%)` 或纯深蓝 #16263F。

## 2. 颜色系统

| 角色 | hex | 面积 | 用途 |
| :--- | :--- | :--- | :--- |
| 主色 | `#16263F` 深海军蓝 | ≤60% | 封面/深色块/标题 |
| 辅色 | `#DCE7F5` 冰蓝 | ≤30% | 卡片底/浅色块 |
| 强调色 | `#FF9F1C` 琥珀橙 | ≤10% | 巨型数字/CTA/焦点 |
| 亮点青 | `#22D3EE` | ≤8% | AI 亮点/装饰 |
| 中性 | `#1B2733` / `#5B6B7A` / `#F5F7FA` | 剩余 | 正文/次要/页面底 |

- 渐变：`linear-gradient(135deg, #16263F 0%, #1E3A5F 100%)`。
- 半透明：深色块内嵌 `rgba(255,255,255,0.06)` 卡、`rgba(220,231,245,0.15)` 边框；装饰圆 `opacity 0.12`。
- Hero 页（P1/P5/P11）强调色占比 15-20%；Supporting 页强调色 ≤5%。

## 3. 字体系统

| 层级 | 字号 | 字重 | 行高 | 用途 |
| :--- | :--- | :--- | :--- | :--- |
| 封面主标题 | 52px | bold | 1.2 | 仅封面 |
| 章节大字 | 44px | bold | 1.2 | 深色巨数页标题 |
| 巨型数据 | 68px | bold | 1.0 | 锚点数字（P2/P5） |

| 卡片小标题 | 20px | bold | 1.4 | 卡片头 |

- 字体：中文「思源黑体」、西文「Inter」，代码「JetBrains Mono」（≤2 中文字体家族）。
- 巨型数据必须 bold + 与正文不同字重（68px vs 15px）。

## 4. 信息密度

- 常规页留白 ≤30%；封面/深色收官页 40%。
- 卡片填充率 ≥85%，卡片正文 ≥80 字（高 ≥320px 卡）。
- 每页 ≥1 视觉锚点（≥44px 元素或 ≥40% B 区图）。

## 5. 配图系统

- 本讲以「数字 + 卡片 + 图标 + CodeBlock」为主视觉，不引入外部配图；术语墙、格局、Q/K/V 均用 Box/Text/FAIcon/CodeBlock 组合还原。
- 图标统一使用 FAIcon（fill 必填），同一卡片组内尺寸统一。
