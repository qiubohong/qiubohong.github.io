## 一、 核心学术论文与大厂报告（Paper & Technical Report）## 1. 行为树与双飞轮机制

* 
* 《AgenticQwen: Training Small Agentic Language Models with Dual Data Flywheels for Industrial-Scale Tool Use》
* 链接：[ACL Anthology 原文链接](https://aclanthology.org/2026.acl-industry.37.pdf)
   * 文献简介：阿里巴巴 PAI 团队针对工业级工具调用发布的 Qwen 智能体论文。详细拆解了如何构建多分支“行为树”以及通过错误驱动、多轮扩展构建双数据飞轮的评测与训练方法。 [1, 2] 
* 

## 2. 真实世界复杂层级规则评测

* 
* 《HSCodeComp: Towards Real‑World and Efficient Agents》
* 链接：[Alibaba 官方技术博客介绍](https://www.alibabacloud.com/blog/603341) | [GitHub 官方项目入口](https://github.com/ATH-MaaS/Marco-DeepResearch)
   * 文献简介：荣获 ACL 2026 最佳资源论文奖（Best Resource Paper）。该基准以海关编码（HS Code）的深度检索与推理为核心，系统论证了在长程、高密度层级规则下如何对 Agent 轨迹进行压力测试。 [3, 4] 
* 

## 3. 2026 最新 DAG 结构与误差传播追踪

* 
* 《AgentEval: DAG-Structured Step-Level Evaluation for Agentic Workflows with Error Propagation Tracking》
* 链接：[Emergent Mind 评测索引页面](https://www.emergentmind.com/topics/agent-eval-checklist)
   * 文献简介：2026 年最新力作，文章将多步 Agent 工作流建模为有向无环图（DAG），并提出了一种自动追踪“哪一步工具或规划失误导致全盘崩溃”的误差根因归因打分算法。 [5] 
*

## 二、 核心开源解决方案与评测脚手架（Open-Source Tools）## 1. 轨迹匹配与图执行审计

* 
* [langchain-ai/agentevals](https://github.com/langchain-ai/agentevals) (GitHub)
* 功能定位：专注于 Agent 运行中执行轨迹（Trajectory）审计的现成评估器。完美契合类似 LangGraph 的状态图或行为树分支校验，支持轨迹 LLM 裁判及路径相似度对齐。 [9] 
* 

## 2. .NET 微软生态专用全栈评测

* 
* [AgentEvalHQ/AgentEval](https://github.com/AgentEvalHQ/AgentEval) (GitHub)
* 功能定位：全面集成于 Microsoft.Extensions.AI 和 Microsoft Agent Framework。支持通过流式断言（Fluent Assertion）对 Agent 执行节点和 192+ 红队安全漏洞进行零代码侵入式的自动化可观测性捕获。
* 

## 3. 云原生 / 无侵入 OpenTelemetry 轨迹采集

* 
* AWS 官方最新工程实践：[Agent-EvalKit](https://aws.amazon.com/blogs/machine-learning/evaluate-ai-agents-systematically-with-agent-evalkit/)
* 功能定位：AWS 2026 年发布的标准 Agent 评估工具包。核心逻辑就是利用 OpenTelemetry（OTel）兼容的链路追踪（Tracing），无缝抓取 Agent 行为轨迹生成 Report，并指出代码层面的修改建议。 [10] 
* 

## 4. 高人气、开箱即用的专业 Agent 评估平台

* 
* [Confident AI / DeepEval](https://github.com/confident-ai/deepeval) (GitHub)
* 功能定位：内置 PlanQualityMetric（规划质量指标）和 ToolCorrectnessMetric（工具正确性指标），是企业在 Pytest 中跑 Agent CI/CD 流水线最常用的 Python 开源测试框架。
*
