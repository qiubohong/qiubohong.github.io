# AgentEval：评估 LLM 驱动应用实用性的开发者工具

> 原文：[AgentEval: A Developer Tool to Assess Utility of LLM-powered Applications](https://microsoft.github.io/autogen/0.2/blog/2024/06/21/AgentEval/)  
> 作者：James Woffinden-Luey（微软研究院高级研究工程师）、Julia Kiseleva（微软研究院高级研究员）  
> 发布日期：2024 年 6 月 21 日

## 摘要（TL;DR）

作为开发者，如何评估 LLM 驱动应用在帮助最终用户完成任务方面的实用性和有效性？

为了解答这个问题，我们此前推出了 **AgentEval**——一个用于评估任何 LLM 驱动应用多维实用性的框架，专为协助用户完成特定任务而设计。现在，我们已将其嵌入 AutoGen 库，以便开发者更容易采用。

本文介绍了 AgentEval 的更新版本，新增了验证流程，用于估计 QuantifierAgent（量化智能体）的鲁棒性。更多细节请参阅[相关论文](https://arxiv.org/html/2405.02178v1)。

---

## 简介

AgentEval 是一个综合框架，旨在弥合评估 LLM 驱动应用实用性方面的差距。它利用 LLM 的最新进展，提供了一种可扩展且具有成本效益的替代传统人工评估的方案。

该框架包含三个主要智能体：**CriticAgent（批评智能体）**、**QuantifierAgent（量化智能体）** 和 **VerifierAgent（验证智能体）**，每个智能体在评估应用任务实用性方面都发挥着关键作用。

---

## 三大核心智能体

### CriticAgent：定义评估标准

CriticAgent 的主要功能是根据任务描述以及成功和失败执行的示例，提出一套评估应用的标准。

例如，在数学辅导应用的场景中，CriticAgent 可能会提出以下评估标准：
- **效率（Efficiency）**：解题过程是否高效
- **清晰度（Clarity）**：解释是否清晰易懂
- **正确性（Correctness）**：答案是否正确

这些标准对于理解应用性能的各个维度至关重要。**强烈建议应用开发者利用其领域专业知识对建议的标准进行验证。**

### QuantifierAgent：量化性能

一旦标准确定，QuantifierAgent 就会接手，量化应用在每个标准上的表现。这个量化过程产生对应用实用性的多维评估，提供其优势和劣势的详细视图。

### VerifierAgent：确保鲁棒性和相关性

VerifierAgent 确保用于评估实用性的标准对最终用户有效，同时保持鲁棒性和高判别力。它通过两个主要行动来实现：

**1. 标准稳定性（Criteria Stability）**
- 确保标准是必要的、非冗余的且可一致衡量的
- 迭代生成和量化标准，消除冗余，评估其稳定性
- 只保留最鲁棒的标准

**2. 判别力（Discriminative Power）**
- 通过引入对抗性示例（噪声或受损数据）来测试系统的可靠性
- 评估系统区分这些示例与标准案例的能力
- 如果系统失败，则表明需要更好的标准来有效处理各种条件

---

## 灵活且可扩展的框架

AgentEval 的一个关键优势是其灵活性。它可以应用于各种任务，无论成功是否有明确定义：

- **成功有明确定义的任务**（如家务）：框架可以评估是否存在多个成功解决方案以及它们的比较情况
- **更开放式的任务**（如生成电子邮件模板）：AgentEval 可以评估系统建议的实用性

此外，AgentEval 允许融入人类专业知识。领域专家可以通过建议相关标准或验证智能体识别的标准的有用性来参与评估过程。这种**人在回路（Human-in-the-Loop）**的方法确保评估始终基于实际的现实考量。

---

## 实证验证

为了验证 AgentEval，该框架在两个应用上进行了测试：

1. **数学问题求解**：包含 12,500 道具有挑战性的数学题，每题附有逐步解答
2. **ALFWorld**：家务任务模拟，涉及模拟环境中的多轮交互

在两种情况下，AgentEval 都成功识别了相关标准、量化了性能，并验证了评估的鲁棒性，证明了其有效性和多功能性。

## 如何使用 AgentEval

AgentEval 目前有两个主要阶段：**标准生成** 和 **标准量化**（标准验证仍在开发中）。两个阶段都使用顺序 LLM 驱动的智能体来做出判断。

### 阶段一：标准生成

在标准生成阶段，AgentEval 使用示例执行消息链来创建一套标准，用于量化应用在给定任务上的表现。

```python
def generate_criteria(
    llm_config: Optional[Union[Dict, Literal[False]]] = None,
    task: Task = None,
    additional_instructions: str = "",
    max_round=2,
    use_subcritic: bool = False,
)
```

**参数说明**：
- `llm_config`：LLM 推理配置
- `task`：要评估的任务
- `additional_instructions`：给标准智能体的额外指令（可选）
- `max_round`：运行对话的最大轮数（可选）
- `use_subcritic`：是否使用 Subcritic 智能体生成子标准（可选）

**示例代码**：

```python
config_list = autogen.config_list_from_json("OAI_CONFIG_LIST")
task = Task(
    **{
        "name": "数学问题求解",
        "description": "给定任何问题，系统需要尽可能简洁准确地解决问题",
        "successful_response": response_successful,
        "failed_response": response_failed,
    }
)

criteria = generate_criteria(task=task, llm_config={"config_list": config_list})
```

**示例输出**：

```json
[
    {
        "name": "准确性",
        "description": "解决方案必须正确，并严格遵守适合该问题的数学原理和技术。",
        "accepted_values": ["正确", "轻微错误", "重大错误", "不正确"]
    },
    {
        "name": "简洁性",
        "description": "提供的解释和方法应该直接切题，避免不必要的步骤或复杂性。",
        "accepted_values": ["非常简洁", "简洁", "有些冗长", "冗长"]
    },
    {
        "name": "相关性",
        "description": "回应内容必须与所提问题相关，并应解决具体的问题要求。",
        "accepted_values": ["高度相关", "相关", "有些相关", "不相关"]
    }
]
```

### 阶段二：标准量化

在量化阶段，AgentEval 将使用生成的标准（或用户定义的标准）来评估给定的执行链，以确定应用的表现。

```python
def quantify_criteria(
    llm_config: Optional[Union[Dict, Literal[False]]],
    criteria: List[Criterion],
    task: Task,
    test_case: str,
    ground_truth: str,
)
```

**参数说明**：
- `llm_config`：LLM 推理配置
- `criteria`：评估给定任务实用性的标准列表
- `task`：要评估的任务（应与 generate_criteria 步骤中使用的相同）
- `test_case`：要评估的执行链（通常是消息的 JSON 列表）
- `ground_truth`：测试用例的基准答案

**示例输出**：

```json
{
  "actual_success": true,
  "estimated_performance": {
      "准确性": "正确",
      "简洁性": "简洁",
      "相关性": "高度相关"
    }
}
```

## 结论

AgentEval 代表了 LLM 驱动应用评估领域的重大进步。通过结合 CriticAgent、QuantifierAgent 和 VerifierAgent 的优势，该框架为评估任务实用性提供了一个鲁棒、可扩展且灵活的解决方案。

这种创新方法不仅帮助开发者了解其应用的当前性能，还提供了可以推动未来改进的宝贵见解。随着智能体领域的持续发展，AgentEval 这样的框架将在确保这些应用满足用户多样化和动态需求方面发挥关键作用。
