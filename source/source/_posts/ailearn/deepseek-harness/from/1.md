## 1. 项目简介

DeepSeek Harness（`dsh`）是由 DeepSeek AI 开发的开源 Agent 框架。

它采用**一切皆插件**的架构，底层由 [Cordis](https://github.com/cordiverse/cordis) 驱动。Cordis 的设计思路详见论文 [A Programming Paradigm for Spatiotemporal Composability](https://arxiv.org/abs/2506.05338)。

> ⚠️ **开发者预览说明**
>
> DeepSeek Harness 目前处于**开发者预览**阶段，正在快速迭代。**将会有不兼容的破坏性变更（BREAKING CHANGES）。**

## 2. 运行方式

### 2.1 通过 npm 运行（推荐）

安装 [Node.js](https://nodejs.org/) 后，运行：

```bash
npx @deepseek-ai/dsh web
```

命令会启动 Web UI，默认访问地址为 `http://127.0.0.1:3080`。详见 [Web UI 指南](https://deepseek-harness.github.io/deepseek-harness/guide/quickstart)。

### 2.2 从源码运行

从仓库检出后运行：

```bash
git clone https://github.com/deepseek-ai/deepseek-harness.git
cd deepseek-harness
pnpm install
pnpm run build
pnpm dsh web
```
