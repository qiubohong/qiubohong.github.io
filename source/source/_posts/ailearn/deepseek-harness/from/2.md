<!-- more -->

---

## 1. 前置条件：启动 Web UI

请先按照[根目录 README](https://github.com/deepseek-ai/deepseek-harness) 中的说明启动 Web UI；命令会打印其访问地址。

`dsh` 进程会把启动时所在的目录作为默认文件系统位置；全新的 Web UI 则不会选中任何工作区，你需要手动添加一个工作区。

---

## 2. 配置模型

打开 **设置 → 模型**，输入 **DeepSeek API 密钥**并保存。

模型路由会立即可用，不需要重启服务器。

> 💡 **提示**：[模型配置指南](https://deepseek-harness.github.io/deepseek-harness/guide/model-config) 介绍其他提供方和自定义 OpenAI 兼容端点的配置方法。

---

## 3. 选择工作区

点击**选择工作区**，添加启动 `dsh` 时所在的项目目录，然后选中它。

> ⚠️ **注意**：选中工作区前，会话输入框不可用。

---

## 4. 运行任务

启动一个会话并发送：

```
Summarize this repository and identify its main packages.
```

Agent（智能体）可以：

- 读取和编辑工作区文件
- 运行命令
- 委派工作
- 维护计划

如果根据当前权限策略，某项操作需要审批，Web UI 会先询问你。

---

## 5. 后续步骤

完成基础体验后，可以继续探索：

- **配置模型** — 接入更多模型提供方
- **使用 Python SDK** — 通过 Python 代码驱动 dsh
- **使用其他 CLI 模式** — 了解标准、PTC、极简、创造等模式
- **开发插件** — 为 dsh 开发自定义插件

---

## 6. 📝 小结

- DeepSeek Harness Web UI 的快速上手分为四步：启动服务 → 配置模型 → 选择工作区 → 运行任务
- 配置 DeepSeek API 密钥后，模型路由立即生效，无需重启
- 工作区是 Agent 操作文件的根目录，必须先选中才能使用会话
- Agent 支持文件读写、命令执行、任务委派和计划维护
- 权限敏感操作会在执行前弹出审批确认
