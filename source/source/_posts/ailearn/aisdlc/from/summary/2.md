## 最值得你继续深挖的 6 个问题

如果继续做下一轮，我建议不要再停留在厂商产品比较，而是直接进入**架构级研究**：

1. **Anthropic 的 12 Plays vs OpenAI Harness vs GitHub Agentic Workflow vs AWS Kiro**
   → 逐步骤拆解到底有什么不同。
2. **AI Native SDLC 的标准 Artifact Schema**
   → `intent/spec/plan/task/eval/evidence` 应该如何设计。
3. **Code Graph 到底应该放在哪一层**
   → 如何成为 Agent Context Engine，而不是另一个知识库。
4. **Agent Team / Subagent 如何映射 SDLC**
   → Planner / Coder / Reviewer / Tester / Security / SRE 如何协作。
5. **AI Code Quality 如何从“测试”升级为“Evidence + Eval”**
   → 这会直接影响你之前关注的 AI 代码质量问题。
6. **最终落地企业级 AI Native R&D Platform 的完整技术架构**
   → 包括 **Spec、Code Graph、Agent Runtime/Harness、MCP、CI/CD、Eval、Governance、Observability、权限和数据模型**。

其中 **第 6 项实际上已经可以形成一份完整的《AI Native SDLC / AI研发效能平台 v1.0 技术架构设计》**。结合你之前的 Code Graph、90 Workspace Monorepo、CI 和 Agent 研发方向，做出来会比单独参考 Claude Code 或某一个 Coding Agent 更有价值。
