## 1. Electron 是什么

Electron 是一个用 JavaScript、HTML 和 CSS 构建桌面应用的框架。它把 Chromium 和 Node.js 打包进同一个二进制文件里，这样你就能用一套 JavaScript 代码，同时跑在 Windows、macOS 和 Linux 上——不需要任何原生开发经验。

入门的话，官方推荐先看教程，跟着走一遍从开发到发布的完整流程。当然，直接翻 API 文档和示例代码也是个好办法，边看边试。

### 用 Electron Fiddle 跑示例

Electron Fiddle 是官方维护的沙盒工具，专门用来试验 Electron 的各种 API，或者在开发过程中快速验证某个想法。文档里的很多示例代码旁边都有"在 Fiddle 中打开"的按钮，点一下就能直接加载，不用手动复制粘贴。

一个最简单的 Electron 应用长这样：

```js
// main.js
const { app, BrowserWindow } = require('electron/main')
const path = require('node:path')

function createWindow() {
  const win = new BrowserWindow({
    width: 800,
    height: 600,
    webPreferences: {
      preload: path.join(__dirname, 'preload.js')
    }
  })
  win.loadFile('index.html')
}

app.whenReady().then(() => {
  createWindow()
  app.on('activate', () => {
    if (BrowserWindow.getAllWindows().length === 0) {
      createWindow()
    }
  })
})

app.on('window-all-closed', () => {
  if (process.platform !== 'darwin') {
    app.quit()
  }
})
```

## 2. 为什么选择 Electron

Electron 把 Chromium、Node.js 和编写原生代码的能力整合进一个框架，用来构建强大的桌面应用。选择它主要有三个理由。

### 2.1 为什么用 Web 技术

在聊 Electron 本身之前，先说说为什么要用 Web 技术做桌面应用。

Web 技术包括 HTML、CSS、JavaScript 和 WebAssembly，是现代互联网的门面。这些技术已经成为构建用户界面的最佳选择——不管是消费级应用还是关键业务系统，不管是跑在浏览器里还是桌面上。

举几个真实案例：NASA 的任务控制中心用 Web 技术写的；Bloomberg Terminal（每个金融机构都有的那个系统，每用户每年 2.5 万美元）用 Web 技术写的，跑在 Chromium 里；麦当劳的点餐机完全用 Chromium 构建；SpaceX Dragon 2 太空舱用 Chromium 显示界面。

**多功能性**：现代 HTML 和 CSS 让开发者和设计师能充分表达创意。Google Earth、Netflix、Spotify、Gmail、GitHub——不管你的应用需要什么界面，都能用 Web 技术实现。

**可靠性**：Web 技术是地球上使用最广泛的 UI 基础。从 CPU 到操作系统，现代计算机都针对运行 Web 技术做了优化。设备制造商会确保用户能访问网站、播放 YouTube 视频——这也意味着你的应用有一个稳定的基础。

**互操作性**：不管你需要对接什么数据提供商或客户系统，他们基本都考虑过 Web 集成路径。嵌入 YouTube 视频用 Web 技术只需要 30 秒，用其他方式可能要专门组建一个团队。

**普遍性**：有 Web 开发经验的工程师很好找。遇到问题，Google、Stack Overflow、GitHub 上基本都能找到答案。

### 2.2 为什么选 Electron

**企业级可靠**：Electron 稳定、安全、成熟。Slack、Discord、Signal 都用 Electron 做聊天应用；OpenAI 的 ChatGPT 和 Anthropic 的 Claude 用 Electron 做 AI 应用；VS Code、Loom、Canva、Notion、Docker 也都押注了 Electron。

**成熟的生态**：目前估计地球上大多数桌面电脑都至少跑着一个 Electron 应用。Electron 是 OpenJS 基金会的重点项目，与 Node.js、ESLint、Webpack 共享资源和专业知识。

具体来说：
- **可靠的发布节奏**：Electron 每隔一个 Chromium 主版本发布一个新主版本，通常和 Chromium 同一天
- **没有独裁者**：Electron 由多家公司（微软、Slack/Salesforce、Notion 等）共同维护，不依赖单一个人或公司
- **稳定、安全、高性能**：通过把最新版 Chromium、V8 和 Node.js 直接打包进应用二进制文件，Electron 在所有目标平台上提供最佳体验

### 2.3 为什么要打包 Chromium

你可能会问：现代操作系统都自带浏览器和 WebView，为什么还要打包 Chromium？

打包确实增加了维护工作量，也让应用体积变大（大多数 Electron 应用超过 100MB）。但这是值得的权衡：

**稳定性**：用操作系统内置的 WebView，你受限于用户操作系统版本里的浏览器版本。如果遇到 bug，你只能让用户升级操作系统——但如果他们的机器无法升级到最新 macOS 或 Windows 11，你就没有任何办法了。打包 Chromium 让你掌控权在自己手里。

**安全性**：类似地，你可以通过发布应用更新来修复安全漏洞，不需要让用户升级操作系统。操作系统厂商对内置 WebView 的安全更新优先级，远不如对内置浏览器那么高。

**性能**：对于复杂应用，用最新版 Chromium 往往比用内置 WebView 性能更好。虽然内置 WebView 理论上可以共享系统资源，但出于安全原因，应用必须在各自的沙盒里运行，这个优势基本消失了。

### 2.4 开发者体验

**强大的生态系统**：npm 上能找到的任何东西都能在 Electron 里跑。关于 Node.js 的所有资源也适用于 Electron。

**丰富的内置能力**：过去十年，Electron 核心积累了大量功能，让你不需要重新发明轮子。

---

## 3. 📝 小结

- Electron 用 JavaScript + HTML + CSS 构建跨平台桌面应用，底层是 Chromium + Node.js
- Web 技术的多功能性、可靠性、互操作性和普遍性，让它成为桌面 UI 开发的优选
- Electron 是企业级选择，VS Code、Slack、Discord、ChatGPT 客户端都在用
- 打包 Chromium 虽然增加了体积，但换来了稳定性、安全性和性能的掌控权
- 由 OpenJS 基金会支持，多家公司共同维护，不依赖单一厂商
